# دفتر الجيم 🏋️

تطبيق ويب بسيط (PWA) بيشتغل على الموبايل بدون إنترنت، بتسجل فيه أوزانك بالجيم حسب العضلة.

## الفكرة
1. بتفتح التطبيق بتشوف **خريطة الجسم** (أمام / خلف).
2. بتضغط على العضلة (مثلاً: صدر علوي) ← بتختار التمرين (بنش مائل بار) ← بتسجل الوزن والعدّات.
3. المرة الجاية بيذكّرك شو رفعت آخر مرة وبيقترح عليك هدف اليوم.

## المميزات
- **خريطة عضلات تفاعلية** ملونة حسب التعافي: 🔴 تدربت اليوم · 🟡 بتتعافى (1–3 أيام) · 🟢 جاهزة.
- **اقتراح هدف اليوم** (Progressive Overload): إذا وصلت 12 عدّة بيقلك زيد الوزن، غير هيك زيد عدّة.
- **مدرب التطور** (مبني على أسس علمية): بيقلك متى تزيد العدّات ومتى تكسر الوزن (قاعدة «2 لـ 2» من NSCA، وزيادة 2.5% للجزء العلوي و5% للأرجل حسب ACSM)، وبيكشف الثبات (البلاتو) والأداء النازل مع نصايح للتعامل معهم.
- **تعافي WHOOP**: بتدخل نسبة التعافي اليومية والمدرب بيعدّل اقتراحاته حسبها.
- **أرقام قياسية**: تنبيه لما تكسر أعلى وزن إلك، مع أقصى تكرار تقديري (1RM).
- **رسم بياني** لتطور الوزن بكل تمرين.
- **حاسبة الأقراص**: بتعرف شو تحط على كل جهة من البار (بار 20 كغ، أقراص أولمبية بألوانها).
- **مؤقت راحة** بيشتغل تلقائياً بعد كل مجموعة، مع اهتزاز وصوت.
- **سجل يومي** لكل التمارين، وإضافة تمارين خاصة فيك.
- **94 تمرين** لكل العضلات، مع **صورة توضيحية** جنب كل تمرين وصورة متحركة (بداية/نهاية الحركة) بصفحة التمرين.
- **طريقة الأداء** لكل تمرين: الخطوات، النصائح، الأخطاء الشائعة، وتنبيهات الأمان.
- **نسخة احتياطية** (تصدير / استرجاع) — البيانات محفوظة على جهازك فقط.

## التشغيل
ما في أي build. افتح `index.html`، أو شغّل سيرفر محلي:

```bash
python3 -m http.server 8000
```

### تنزيله على الموبايل
فعّل **GitHub Pages** للريبو (Settings ← Pages ← Branch)، افتح الرابط من الموبايل واختار
**"إضافة إلى الشاشة الرئيسية"** — بيصير يشتغل كتطبيق وبدون إنترنت.

## الملفات
- `index.html` — التطبيق كامل (واجهة + منطق)
- `guides.js` — شرح طريقة الأداء لكل تمرين وربط الصور
- `img/ex/` — صور التمارين
- `manifest.json`, `sw.js`, `icons/` — تثبيت التطبيق والعمل بدون إنترنت
